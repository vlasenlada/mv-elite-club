
# M&V Elite Club

Вебзастосунок онлайн-школи англійської мови,
математики та підготовки до НМТ.

## Технології
- Python
- Django
- HTML, CSS
- SQLite (локальна розробка)

## Функціональність
- Реєстрація та авторизація
- Ролі користувачів
- Каталог курсів
- Особистий кабінет учня
- Заявки на навчання
- Адміністративна панель
- Управління заняттями

## Статус
Проєкт перебуває в розробці.
